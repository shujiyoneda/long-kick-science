# 画面・デザインシステム

対象：中高生のサッカー選手。問い→導出→計算→技術応用の往復を中心に据える。

## ページ

- `/`：学習開始・公開3講座・シミュレーター・8章のマップ。
- `/chapters/`：8章24講座。公開/未公開を各カードに表示。
- `/chapters/01/`〜`08/`：章の紹介、3段階の講座、到達目標。
- `/learn/01-1/`〜`08-3/`：共通テンプレート。06-1〜06-3のみ本文完成。
- `/simulator/`：3入力、飛距離・最高点・滞空時間、等縮尺のPlotly軌道、データ表。
- `/references/`：原典・書誌・各出典の適用範囲。
- `/about/`：学び方、科学的な区分、モデルの限界。
- `/404.html`：復帰導線。

合計38 HTML。公開3講座・計画21講座を状態データで管理。

## トークン

- 背景 #f7f8f3、本文 #142b30、補足 #596a69、強調 #287365。
- ヒーロー #142b30、アクセント #d3f584、境界 #dce2d9。
- 見出しはシステム日本語ゴシック、数値・章番号は等幅。外部フォントなし。
- 横幅1240 pxまで。本文780 px、デスクトップ目次230 px。
- 760 px以下は1カラム。カード・シミュレーターの操作部→結果の順。
- 図はインラインSVG。科学図を装飾画像で置き換えない。

## 操作とアクセシビリティ

セマンティックなheader/nav/main/article/footer、スキップリンク、フォーカス表示、ラベル付き数値入力、キーボード対応スライダー、計算結果のlive region、SVGの説明、数式のMathML、横スクロール可能な数式領域、Plotlyと同内容の数値表。画面全体は横スクロールさせない。動きを抑えるOS設定と印刷に対応。
